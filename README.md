# Basic Beny website

Static marketing site for [basicbeny.com](https://basicbeny.com), operated by Rhodes Resonance LLC.

## Local preview

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Production

- Hosting: Cloudflare Pages
- Production branch: `main`
- Build command: none
- Output directory: repository root
- Custom domain: `basicbeny.com`

Changes should be made on a branch and merged through a pull request after local and preview verification.
